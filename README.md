# Namizna aplikacija [Kviz]

## 📋Opis
Dobili smo navodilo, naj ustvarimo kviz. Izbrali smo si lahko katero koli temo, navodila so nam pa bila podana. Ustvaril sem kviz kjer si si na začetku izbral temo in začel z reševanjem. Uporabljal sem **Apache NetBeans** (IDE okolje). Za celoten projekt sem porabil približno **6 ur**.

## 💡Kaj sem se naučil
Spoznal sem kako deluje program **Apache NetBeans**. Poleg tega sem se nekaj stvari naučil tudi s strani programiranja, ker moraš tudi sprogramirat, če želiš, da potem vse skupaj deluje. Zdaj vem kako delujejo **frami**, **labeli**, **radio buttoni**,...
